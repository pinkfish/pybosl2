Version¶

class pybosl2.version.Version(version='0.6.3')[source]¶

Bases: object

A semantic major.minor.update version.

Exposes each numeric component and a string form, so callers can branch on version.major/version.minor/version.update or render str(version).

Parameters:

version (str) – A dotted version string such as "1.2.3" (an optional leading v is accepted). Missing trailing components default to 0 — e.g. "1.2" parses as 1.2.0. Defaults to the package __version__.
