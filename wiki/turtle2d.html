Turtle2D¶

2-D turtle-graphics path builder

2-D turtle-graphics path builder.

Implements BOSL2’s turtle2d() command language for generating 2-D paths. All commands operate in the XY plane; z-coordinate operations raise a ValueError.

Shares the TurtleCommandType and TurtleCommand definitions with pybosl2.turtle3d so that both turtles accept the same command set.

pybosl2.turtle.turtle2d.turtle2d(commands, state=None, repeat=1)[source]¶

Build a 2-D path from TurtleCommand objects — BOSL2’s turtle2d().

Creates a Turtle2D, runs commands (optionally repeat times), and returns the turtle. Access the path via Turtle2D.points() or the state via Turtle2D.full_state().

Args:

commands: A flat list of TurtleCommand objects. state: Optional starting Turtle2DState. repeat: Number of times to repeat the command list.

Returns:

The Turtle2D instance after executing all commands.

Examples:

A rounded-corner square drawn with arcs:

from pybosl2.turtle2d import turtle2d
from pybosl2.points import Point

from pybosl2.turtle3d import TurtleCommand, TurtleCommandType as Tct

path = turtle2d([

TurtleCommand(Tct.MOVE, size=40), TurtleCommand(Tct.ARCLEFT, radius=8), TurtleCommand(Tct.MOVE, size=40), TurtleCommand(Tct.ARCLEFT, radius=8), TurtleCommand(Tct.MOVE, size=40), TurtleCommand(Tct.ARCLEFT, radius=8), TurtleCommand(Tct.MOVE, size=40), TurtleCommand(Tct.ARCLEFT, radius=8),

]).points() path.stroke(width=3, closed=True).linear_extrude(height=4).show()

class pybosl2.turtle.turtle2d.Turtle2D(state=None)[source]¶

Bases: object

A 2-D turtle: walk it with a command list to produce a 2-D path.

The turtle starts at the origin pointing along +X with a step length of 1. The turtle’s internal state is a Turtle2DState instance accessible via full_state().

Examples:

A rounded-corner square:

from pybosl2.turtle2d import Turtle2D
from pybosl2.points import Point

from pybosl2.turtle3d import TurtleCommand, TurtleCommandType as Tct

cmds = [

TurtleCommand(Tct.MOVE, size=40), TurtleCommand(Tct.ARCLEFT, radius=8), TurtleCommand(Tct.MOVE, size=40), TurtleCommand(Tct.ARCLEFT, radius=8), TurtleCommand(Tct.MOVE, size=40), TurtleCommand(Tct.ARCLEFT, radius=8), TurtleCommand(Tct.MOVE, size=40), TurtleCommand(Tct.ARCLEFT, radius=8),

] path = Turtle2D().run(cmds).points() path.stroke(width=3, closed=True).linear_extrude(height=4).show()
