Points¶

Lightweight 2‑D / 3‑D point and vector types shared across the pybosl2 geometry layer

Lightweight 2‑D / 3‑D point and vector types shared across the pybosl2 geometry layer.

Provides Point (immutable, x/y/optional z) and Vector (mutable list subclass with elementwise arithmetic). Both support 2‑D and 3‑D variants and integrate with numpy, shapely, and path operations.

class pybosl2.points.Point(x, y, z=None)[source]¶

Bases: object

An immutable 2‑D or 3‑D point.

If z is None the point is 2‑D (is_2d returns True); a concrete z makes it a 3‑D point. Supports iteration, indexing, len(), arithmetic, and np.asarray().

Examples

from pybosl2.points import Point

p2 = Point(10.0, 20.0)
assert p2.is_2d
assert len(p2) == 2

p3 = Point(10.0, 20.0, 5.0)
assert not p3.is_2d
assert len(p3) == 3

class pybosl2.points.Vector(x, y=None, z=None)[source]¶

Bases: list[float]

A 2‑ or 3‑element list that supports elementwise arithmetic.

Inherits from list[float] so it is a drop‑in for [x, y] or [x, y, z] lists. Elementwise +, -, * replace the default list concatenation/repetition.

len() == 2 means a 2‑D vector (is_2d is True); len() == 3 is a 3‑D vector. Use to_3d() to add a Z coordinate.
