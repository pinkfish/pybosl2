Polyhedra¶

⚙️ Spec sheet →  —  visual schematic and metrics measured from a real rendered STL.

The five Platonic solids from BOSL2’s polyhedra.scad, built as watertight polyhedra. regular_polyhedron() builds tetrahedron / cube / octahedron / dodecahedron / icosahedron (with named convenience methods too), sized by circumradius, diameter, inradius or side length. The dodecahedron is derived as the dual of the icosahedron. The Archimedean, Catalan and stellated families are a follow-up.

static regular_polyhedron(name=PlatonicSolid.CUBE, radius=None, diameter=None, inner_radius=None, side=None)[source]¶

A Platonic solid, sized by circumradius radius, diameter diameter, inradius inner_radius, or side (BOSL2 regular_polyhedron()).

name is a PlatonicSolid enum or string like "tetrahedron" / "cube" / etc. (short aliases accepted). Defaults to circumradius 1.

Examples

A dodecahedron:

from pybosl2.parts.polyhedra import Polyhedra, PlatonicSolid
Polyhedra.regular_polyhedron(PlatonicSolid.DODECAHEDRON, side=12).show()
