# pybosl2 — conformance history

Every requirement that was open and is now closed, with what was wrong and what fixed it.
**Append-only.** A row lands here in the same commit as the code, moved from
[SPEC.md §12.2](SPEC.md#122-open) per SPEC §13 rule 4.

This was §12.1 of the spec until T27. It is 40% of that document by volume and none of it is
contract: it is the record of how the contract got to be true, which is worth keeping and
worth keeping out of the way of a reader looking for the rules.

## Closed

| Requirement | What was wrong | Resolution |
|---|---|---|
| **PAR-5** | The SDF `pie_slice` stored the full disc's bounding box rather than the wedge's, so `bounds()` over-reported on the backend whose selling point is exact bounds — at 30° by four times the area (20×20 for a wedge occupying 10×5) | `_sector_xy_bounds()` computes the sector's own box from the apex, the two arc endpoints and whichever axis directions the sweep passes through; anchoring still uses the full cylinder, as the CSG `pie_slice` does, so an anchored slice lands in the same place on both backends. `BOUNDS_NOT_YET_EXACT` is now empty and `pie_slice` joins the cross-backend bounds agreement check |
| **C-8 / C-9** | Three `texture` functions threaded the two halves of a mesh through separately — `is_watertight_topology(verts, faces)`, `rasterize_vnf_texture(verts, faces, …)` and `vnf_tile_to_solid(verts, faces, …)`, which also *returned* a bare pair. Nothing checked that the indices in `faces` were in range for `verts`, so a caller could mix two meshes and get silent nonsense; `is_watertight_topology` took `verts` and discarded it unread, which is the split showing through | `VNF.is_watertight()` added as a mesh method (C-9) — the check had no home on the mesh type at all — and the other two now take and return a `VNF` (T25). `textured_tile` converts BOSL2's `(verts, faces)` texture tuple once, at the boundary. Guarded by `tests/test_vnf.py::test_is_watertight_reads_topology_not_geometry` and `tests/test_texture.py::test_the_tile_functions_trade_in_meshes_not_halves` |
| **C-7a / C-7b / C-7c / C-7d** | A public parameter meaning an ordered set of points accepted a bare sequence or a NumPy array, so every callee re-derived dimension, closed-ness and winding — and disagreed: the same list was a 2-D outline to one function and a degenerate 3-D path to the next. The permissive `PathLike` alias was never marked internal, so it spread to 51 public signatures as though it were the contract | All 51 converted to `Path2D`/`Path3D`/`Path` with `require_path()`/`require_paths()` guarding on the first line (T24); `PathLike` is documented internal (C-7c) and 8 carve-outs — normalizers, per-sample kernels and mesh vertex arrays — are named with their reason. `expect=` checks the *width*, because `Path2D` and `Path3D` are siblings and a bare `Path` check let a 3-D path into planar arithmetic (C-7d). Guarded by `tests/test_polyline_parameters.py`: an empty ratchet with a negative control, plus `test_a_path_annotation_is_backed_by_a_guard`, which caught five parameters that were typed but never checked |
| **B-9** | The façade exposed only the *intersection* of the two backends, so 146 CSG parameters were unreachable through `pybosl2.solid` and `for_backend()` dropped a caller-supplied one silently rather than refusing it — `cube(spin=45)` came back unrotated on SDF | The façade exposes the union; `refuse_unhonoured()` raises `UnsupportedByBackendError` naming any argument the active backend cannot honour, with carve-outs for tessellation (`fn`/`fa`/`fs`/`res`/`realign`) and for a value that asks for nothing (a declined `rounding=0`). All 146 parameters are reachable now, kept that way by `test_the_facade_exposes_every_shared_constructors_full_surface` |
| **B2-1** | Feature parity with BOSL2 was claimed and never measured; no gap list existed | `docs/bosl2_coverage.rst`, generated by `docs/_covgen.py`: all 56 upstream `.scad` files of BOSL2 v2.0.751 against the module that ports each one — 42 ported, 3 partial (with the gap named), 11 with nothing to port. `tests/test_bosl2_coverage.py` fails if a row names a module that no longer exists, if a partial row does not say what is missing, or if the committed page drifts from the generator; `_covgen.py --refresh` re-checks the file list against upstream |
| **P-8** | Three geometry areas were still loose function families where the rest of the library uses classes: the mask profiles, the metaball primitives, and the turtle command language | `Mask2D`/`Mask3D` and `Metaball` own their factories (`Metaball.sphere(...)`, `Mask2D.roundover(...)`), with `Metaball.at()` placing a field and the `mb_*`/`mask*_*` spellings kept as aliases; the turtles gained a method per command (`Turtle2D().move(40).arc_left(radius=8)`) from one shared table, and the command language moved to `pybosl2/turtle/commands.py` so all three modules can share it |
| **R-4** | No ambient resolution defaults; `fn`/`fa`/`fs`/`res` had to be threaded through every call | `pybosl2/defaults.py`: `use_defaults()` / `set_defaults()` / `reset_defaults()`, resolved in `frag_count`, the native cylinder/sphere/circle wrappers, and both backends' `construct` |
| **A-4** | The top-level package had no stub, so its lazy exports were invisible to type checkers and IDEs | `pybosl2/__init__.pyi`, kept in step by `tests/test_init_stub.py` |
| **A-4 / P-5** | Backend switching was reachable only through a private module | `use_backend`, `set_default_backend`, `current_backend`, `known_backends` (plus the defaults API and the error types) are now top-level exports |
| **D-3** | 19 mutable list defaults in signatures, 9 more in stubs | All converted to tuples; guarded by a test that scans the package |
| **B-8 / P-2** | The façade deferred to backend defaults silently | `effective_defaults(shape, backend=None)` reports them live off the constructor |
| **D-8** | `prismoid()` and `regular_prism()` presented backend-required arguments as optional | Made honestly required; guarded by a façade-honesty test |
| **E-4 / P-1** | `rect_tube()`, `torus()`, `tube()` asserted on user input; empty booleans raised `reduce()` errors | All replaced with `ValueError`s naming the accepted spellings; `rect_tube` now derives a 1 mm wall from an outer size alone |
| **C-1** | The 2-D shape protocol was typed `Any -> Any`, so 2-D chains lost static checking | `Flat` and `Solid` protocols fully typed |
| **R-1** | `rect_tube` rounds corners but took no facet controls | `fn`/`fa`/`fs` accepted and passed to both prismoids |
| **D-5** | A conflicting `radius=`/`diameter=` pair was resolved silently by priority, so a typo built the wrong size | `pick_radius()` raises `ValueError` naming both parameters; all 34 inline resolutions across the package now route through it |
| **S-2 / C-1** | The `Flat` contract had no `bounds()`, so 2-D shapes could not be measured through the protocol | `bounds()` added to `Flat`; both 2-D implementations already provided it |
| **S-47 / DOC-1** | `path2d`, `path3d`, `points`, `bounds`, `caps` and `surfaces3d` were tagged `internal` while holding top-level public API, so paths, strokes/caps, bounds and heightfields had no reference page | Retagged into public categories; seven reference stubs generated |
| **PAR-3** | The CSG-only list claimed 2-D geometry as CSG-only, which stopped being true when the SDF backend gained `PyShape2D` | Rationale corrected in the spec and in the code comment: only `projection` and `fill` are CSG-only |
| **C-14 / S-51** | `shape` was a method on all 50 part classes while the spec specified a property, and `show()` returned `None` | `@property` with the existing lazy cache; 551 call sites rewritten; every `show()` returns the shape |
| **A-7** | `pybosl2.parts.__all__` advertised `Threading`, which does not exist | Removed; `tests/test_exports.py` walks every public module's `__all__` |
| **C-15 … C-18** | `Solid` and `Flat` were parallel contracts that had already drifted (`Flat` lacked `bounds()`, was typed `Any`) | One `Shape` protocol with `Self`-returning members; `Flat` and `Solid` extend it and declare only what is dimensional |
| **PAR-3** | `projection` was listed CSG-only *and* implemented on `SdfSolid` by meshing, so the refusal never fired and an SDF shape silently produced CSG geometry | Method removed, refusal names `.to_csg()`; every exclusive entry carries its reason; `tests/test_backend_parity.py` checks the lists against the classes; the stale design doc rewritten |
| **PAR-1 / C-19 / B-5** | The SDF shape's `__getattr__` meshed the field to answer any method it lacked, returning a raw native handle — 19 names, including every directional move and all of colour | Moves and colour implemented natively (colour rides the field as metadata); attachment state moved to the CSG-only list; the fallback is a documented mesh-operations allowlist and everything else refuses, naming `.to_csg()` |
| **R-5** | `fn=0` as the opt-out from an ambient `fn` was undocumented and untested | Documented in four places and covered by a test |
| **Q-4** | The minimum-argument check covered only `pybosl2.solid` | Parametrised over the four public shape modules plus a parts probe; it immediately found eight more E-4 violations and one missing `__all__` |
| **R-1** | 50 public curved-geometry callables took no facet controls, so ambient resolution could not reach them | 18 fixed and 32 triaged out of scope under R-1a (placement, caller-supplied sampling, or descriptors); the backlog list is empty and `tests/test_facets.py` keeps it that way |
| **E-4** | 290 `assert`s validated user input, so `python -O` deleted the checks and bad input silently produced wrong geometry | All converted to `ValueError` naming the accepted spellings; 65 tests updated to assert the type *and* the message; a ratchet test walks the AST so it cannot come back. 25 asserts remain, all genuine internal invariants |
| **DOC-2 / D-P5** | 27 façade callables — the recommended entry point — had no `Args:` and no example, so `help(pybosl2.cuboid)` taught nothing | Descriptions and examples lifted from the backend constructors they delegate to; two tests keep them present and runnable |
| **S-46a** | 17 parts still built CSG geometry inside an `sdf` block through paths no constructor guard covers | `@csg_part` on every part's `shape` property: all 53 refuse uniformly, naming the way forward |
| **A-6** | The top level mixed neutral names with CSG-only ones, so an `sdf` block quietly built CSG geometry | The four with SDF twins dispatch through the façade; the rest refuse with a hint. A test asserts no top-level name returns a CSG shape inside an `sdf` block |
| **B-3 / PAR-5** | The façade defaulted shared arguments to `None` and forwarded only what the caller passed, so an identical call could resolve differently per backend | 64 shared defaults lifted into the façade; backends filter by what their constructor declares; `effective_defaults()` reports the façade first. A convergence test asserts both backends place and size a bare call alike |
| **A-4 / DOC-1** | `import pybosl2` pulled `webcolors` eagerly, so it failed inside the PythonSCAD app and broke 89 rendered examples; promoting path2d/path3d generated second pages for modules `paths.rst` already documented, giving 266 duplicate-object warnings | `Color` and `webcolors` are lazy (hex parsed locally); `_rstgen` skips modules a committed page documents; dataclass fields use `#:` comments. Docs build: 0 warnings |
| **C-1 / E-3** | `CsgSolid` read `current_backend()` into its own tag, so a CSG solid built inside a `use_backend("sdf")` block claimed to be SDF and the cross-backend guard never fired | The tag is a class constant; `backend_only()` makes a backend's own constructors refuse elsewhere (64 of them) and `builds_with()` scopes CSG internals that legitimately build CSG |
| **S-48 … S-50** | `show()` was reachable only through the native passthrough, so it was in no contract and — under Python 3.12's protocol rules — `isinstance(shape, Flat)` was false for every CSG shape | Declared on `Flat`/`Solid` and implemented as a real method on the CSG base, on `SdfSolid` (meshes, as rendering must) and on the 2-D SDF shape (refuses, naming the extrusion) |
| **C-18** | `Shape2D` was a second name for `Flat`, exported alongside it | Removed; `Flat` is the only spelling |
| packaging | `requires-python = ">=3.10"` with a 3.10 classifier, but `StrEnum` (3.11+) is used in ~30 places | Floor raised to 3.11 |
| hygiene | `distributors.py.bak` shipped inside the package; 854 MB of pytest scratch in the repo root | Removed; `pytest-of-*/` ignored and scratch retention capped |
| **S-2b** | `bounds()` meant four different things: `(centre, size)` from shapes, a `Bounds2D`/`Bounds3D` from paths and `VNF`, a NumPy `[[min], [max]]` from `Region`. `lo, hi = solid.bounds()` — the obvious reading — silently bound a *centre* to `lo`, and the protocols typed it `tuple[list[float], list[float]]` so the checker could not help | Every `bounds()` in the library returns `Bounds2D`/`Bounds3D`, narrowed per dimension on `Flat`/`Solid`; the boxes gained `from_center_size()`/`from_min_max()` and `min`/`max`, so no call site does the arithmetic. The raw pair is `_center_size()`, private. `bounding_box()` and `nominal_size` are gone (C-21). `tests/test_bounds_contract.py` walks every type with a `bounds()`; unpacking one is now a `TypeError` rather than a silent mis-read |
| **C-20 / C-22** | The `Solid` protocol declared 32 members; `CsgSolid` had 92. `attach`, `diff`, `tag`, `projection`, every edge treatment and the whole distribution family were invisible to a type checker, so `def f(base: Solid) -> Solid: return base.attach(...)` — a caller following PLAN §2 — did not compile | The shared surface is declared on `Shape` (colour, tagging, attachment, distribution, the in-plane moves) and the dimensional half on `Flat`/`Solid`. The distribution family is typed `list[Self]`, which is what it actually returns. `_shape.pyi` had drifted too — `minkowski` was on the class and not the stub, which failed 56 docstring examples |
| **C-21** | Five synonym pairs on the shape surface (`nominal_size`/`size`, and `bounding_box()` beside `bounds()`) | `size` is the one name for the nominal anchor box on both backends; `nominal_size` removed |
| **S-19a / S-19b / S-19c** | The sweep family returned `VNF \| Solid \| list[list[list[float]]]`, so its own documented one-liner failed `mypy --strict`; every caller appended `.polyhedron()`; and `path_sweep` wound its mesh opposite to `linear_sweep` — −1000 against +1000 for the same box, which makes a cut *add* material | Every sweep returns a `Solid` with the mesh on `.vnf()`; `transforms=True` became `path_sweep_transforms()` / `Bezier.sweep_transforms()` (S-19b); winding is normalised at the one exit the family shares. `tests/test_sweep_contract.py` cuts with each member and asserts the volume went down — the guard that existed for `linear_sweep` alone |
| **S-53 / S-54 / S-55** | There was no export at all: §6.13 was titled "import, export and interchange" and specified only import, so a user could display a part but not save it | `pybosl2/export.py` writes STL (binary and ASCII), OBJ, OFF and PLY from a `VNF` in pure Python — no native runtime, guarded by a test that stubs the imports out. `Shape.export()`, `VNF.export()` and `Part.export()`; `VNF.from_solid()` is the way back across the mesh boundary. Export validates watertightness and winding and refuses to write a mesh that would add material where it cuts, with `check=False` for a deliberately open surface |
| **E-1** | `except Bosl2Error` caught none of the ~570 validation errors: E-4 required `ValueError` and E-1 required `Bosl2Error`, and nothing was both | `Bosl2ValueError(Bosl2Error, ValueError)`; all 570 sites converted, messages unchanged, every existing `except ValueError` still works.
